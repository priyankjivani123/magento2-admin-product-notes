# Changelog - Magento 2 Admin Product Notes

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-11-09
### Added
- Initial open-source release under MIT License.
- Complete Admin UI Grid and Form under Catalog > Product Notes.
- Searchable product dropdown selector in admin edit form.
- Declarative schema table `priyankjivani_product_notes`.
- Full REST Web API endpoints (`GET /V1/productnotes/product/:productId`, `POST /V1/productnotes`).
- Automated PHPUnit unit tests for data models.
- Strict PHP 8.1 - 8.4 compatibility with zero implicit nullable types.
